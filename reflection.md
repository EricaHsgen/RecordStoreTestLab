1. require_login() forces the user to be logged in in order to view pages other than login_form.php and register_form.php. It runs when trying to view any other pages by clicking on links in the nav. It ensures the site stays secure so that only users with an account can view certain pages (such as checkout, which uses information from the users table -- users without an account would cause problems with the way the database is handled, which is why only users with an account can access those pages).
2. First, the program trims down input and corrects any empty fields. Then, the input is validated by making sure it is not empty and it matches the information in the database (first the username is searched in the database, then the raw password inputted is validated against the one found in the database by decrypting it using the input). The files that handle the logic are both functions.php (user_find_by_username()) and index.php using the login case in the switch statement. The session variables set after a successful login are user_id and full_name (view is also set, but it is not a session variable).
3. $_SESSION['cart'] is an array of integers (or an empty array, if no integers are inside of it) that correlate with the ids in the record table. When you click Add to Cart, you are adding an integer to an array. 
4. the $records_in_cart variable comes from the index page on line 171. We need records_by_ids() function in functions.php because a collection of numbers mean nothing to the average user, displaying the information associated with each ID by creating a query to the database is more useful and informing.
5. When you click on complete purchases, the array of ids in the cart ($_SESSION['cart']) is stored in an array ($cart_ids on line 114). A for-loop is ran for each item in the array that, for each item, a new record is created in the purchase table with the purchase_create() function, using the user's user id and the record stored id in the array as arguments. After that, the original array ($_SESSION['cart']) is cleared.
